Port web i sistemit Python (console) për menaxhimin e hotelit.

## 🎬 Demo live

Hap `index.html` ose `demo/index.html`. Hapat ndjekin `HMS.py`:
1. Të dhënat e klientit (emri, adresa, check-in/out, nr. dhome 101+)
2. Qiraja e dhomës — Tipi A Rs 6000, B Rs 5000, C Rs 4000, D Rs 3000 për natë
3. Restoranti — ujë Rs 20, çaj Rs 10, mëngjes Rs 90, drekë Rs 110, darkë Rs 150
4. Lavanteria — Rs 3/4/5/6/8 sipas artikullit
5. Lojërat — pingpong Rs 60, bowling Rs 80, snooker Rs 70, video-lojëra Rs 90, pool Rs 50 për orë
6. Fatura — nëntotali + shërbime shtesë Rs 1800 = totali
